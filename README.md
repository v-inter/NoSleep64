# NoSleep64

Утилита на чистом ассемблере (FASM x64) для предотвращения включения скринсейвера и перехода Windows в спящий режим. Работает в фоне без графических окон и потребляет 0% процессора.

## Как это работает
Программа использует системную функцию `SetThreadExecutionState` с флагами `ES_CONTINUOUS | ES_SYSTEM_REQUIRED | ES_DISPLAY_REQUIRED`.

## Как использовать
1. Скомпилируйте файл `NoSleep64.asm` через FASM.
2. Запустите полученный `NoSleep64.exe`.
3. Чтобы закрыть программу, завершите процесс `NoSleep64.exe` в Диспетчере задач или через консоль: `taskkill /f /im NoSleep64.exe`.
