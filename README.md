# NoSleep64

Утилита на чистом ассемблере (FASM x64) для предотвращения блокировки экрана, запуска скринсейвера и перехода Windows в спящий режим. Работает в фоне, не имеет графических окон и потребляет 0% ресурсов процессора.

## Как это работает
Программа использует системную функцию `SetThreadExecutionState` с флагами `ES_CONTINUOUS | ES_SYSTEM_REQUIRED | ES_DISPLAY_REQUIRED`.

### 🚀 Как использовать утилиту
1. Запустите полученный файл NoSleep64.exe.
2. Программа запустится в скрытом GUI-режиме: у нее нет окон, она не отображается на панели задач, но сразу начинает удерживать систему активной.
3. Проверить, что процесс успешно запущен и висит в памяти, можно через Командную строку (или Far Manager) следующей командой:

cmd

tasklist | findstr /I "NoSleep64.exe"

4. **Как выключить программу:** Поскольку у нее нет графического интерфейса, закрыть её можно через *Диспетчер задач* (вкладка «Подробности», найти NoSleep64.exe и нажать «Снять задачу») либо одной командой в консоли:

cmd

taskkill /f /im NoSleep64.exe

После закрытия процесса операционная система Windows вернется к своим стандартным настройкам энергосбережения и блокировки экрана.

### 🎯 NoSleep64  Зачем нужно?

Если настроены **групповые политики безопасности (GPO)**. Экран компьютера автоматически блокируется, если за ним никто не сидит более 5–10 минут.

Это создает огромные неудобства, если вам необходимо:

* **Контролировать мониторинг:** следить за логами, графиками, серверами или долгими процессами рендеринга/компиляции в реальном времени, не прикасаясь к мыши.
* **Оставаться «в сети»:** предотвратить уход рабочего мессенджера (Teams, Skype, Slack) в статус «Аватар/Отсутствует», пока вы читаете документацию с листа или отошли налить кофе.

Обычно для этого используют громоздкие сторонние утилиты или скрипты автоматизации (вроде MoveMouse или скриптов на PowerShell, которые бесконечно жмут клавишу F15). Однако такие скрипты и тяжелые программы часто **блокируются корпоративными антивирусами** или службами ИТ-безопасности.

### ⚡ Почему выбран именно Ассемблер (FASM)?

1. **Максимальная скрытность и чистота:** Программа не использует эмуляцию нажатия клавиш или движение курсора мыши. Она общается с Windows напрямую через легальный системный API-вызов, который используют все современные видеоплееры (чтобы экран не гас во время просмотра кино).
2. **0% нагрузки на систему:** В отличие от программ на Python, C# или C++, утилите на ассемблере не нужны тяжелые библиотеки, виртуальные машины или среды выполнения. Она весит всего около 1.5–2 КБ и потребляет нулевой ресурс CPU благодаря оптимизированному циклу ожидания (Sleep).
3. **Отсутствие следов:** Программу не нужно устанавливать в систему. Она компилируется в один независимый исполняемый .exe файл, который можно запускать прямо с флешки или из любой папки.

### 🛠️ Как собрать и запустить: Пошаговая инструкция

### Шаг 1. Скачивание и подготовка компилятора

1. Перейдите на официальный сайт компилятора: [flatassembler.net](https://flatassembler.net/).
2. Откройте раздел **Download** и скачайте актуальную версию FASM для Windows (например, fasmw17332.zip).
3. Распакуйте скачанный архив в любую удобную папку на вашем компьютере.

### Шаг 2. Вариант компиляции через GUI (Графический интерфейс FASM)

1. В папке с распакованным компилятором найдите и запустите файл **fasmw.exe** (редактор с графическим интерфейсом).
2. Откройте в нем файл исходного кода NoSleep64.asm (или просто скопируйте код и вставьте в окно редактора).
3. Нажмите комбинацию клавиш **Ctrl + F9** (или выберите в верхнем меню Run -> Compile).
4. В папке с исходным кодом появится готовый файл NoSleep64.exe.

### Шаг 3. Вариант компиляции через Консоль (Командную строку / Far Manager)

Если вы предпочитаете работать в консоли, используйте консольную версию компилятора fasm.exe:

1. Откройте Командную строку (CMD) или Far Manager в папке с вашим исходным кодом.
2. Выполните команду сборки (указав правильный путь к компилятору fasm.exe), например:

cmd

C:\путь_к_папке_fasm\fasm.exe NoSleep64.asm NoSleep64.exe

3. После успешного выполнения команды в консоли отобразится размер созданного файла и количество пройденных фаз компиляции.
